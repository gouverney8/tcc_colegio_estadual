## Observações

- Packs completos que não entram no jogo foram removidos do repositório. Só permanece o que o runtime usa, mais as licenças.
- O antigo pack Retro Casino / Jackpot não é utilizado.
- Itens sem autoria confirmada no ZIP original estão marcados neste documento. Não atribua esses arquivos a um autor inventado.
- Projeto educacional. Para publicação comercial, revise cada licença (em especial Ozzbit Games, FreeSFX e os ZIPs de chefes sem metadados).
