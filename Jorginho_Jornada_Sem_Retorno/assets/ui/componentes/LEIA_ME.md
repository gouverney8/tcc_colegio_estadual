# Componentes ativos da interface

Esta é a pasta principal para os elementos reutilizáveis da interface atual.

- `botoes_madeira/estados/`: imagens sem texto dos estados normal, hover, pressionado, focado e desabilitado. O texto é criado por `Label` no Godot.
- `controles_configuracoes/sliders/`: trilhas e controles dos sliders.
- `controles_configuracoes/toggles/`: estados ligado e desligado.
- `painel_modular_v3/`: fundo, moldura, cantos e guia de montagem do painel sem deformação.
- `placas/`: placas reutilizadas como suporte para títulos.

Não coloque assets antigos nesta pasta. Os itens sem uso encontrados na limpeza foram separados em `PARA_DELETAR/assets` para não aparecerem no FileSystem do Godot.
